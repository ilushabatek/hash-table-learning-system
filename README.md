# HashLearn — обучающая система по хэш-таблицам

Интерактивное веб-приложение на Streamlit для изучения хэш-таблиц
с открытой адресацией и методом цепочек. Позволяет в реальном времени
сравнивать хэш-функции, методы разрешения коллизий и видеть, как данные
распределяются по слотам таблицы.

Курсовой проект.

---

## Возможности

- **Три набора данных** на выбор: пользователи, товары, книги (JSON).
- **Три хэш-функции**:
  - Полиномиальная (`h = h·31 + ord(ch)`)
  - FNV-1a
  - djb2 (Дэна Бернстайна)
- **Три метода разрешения коллизий**:
  - Метод цепочек (chaining)
  - Линейное пробирование (linear probing)
  - Квадратичное пробирование через треугольные числа (quadratic probing)
- **Настраиваемый размер таблицы** (10–32, шаг 1).
- **Поиск по имени** с подсветкой найденного элемента.
- **Цветовая подсветка слотов**:
  - 🟩 одиночный элемент
  - 🟥 начало цепочки
  - 🟨 продолжение цепочки
  - 🟡 пробированный элемент (open addressing)
  - 🟦 найденный элемент
  - ⬜ пустой слот
- **Живая статистика**:
  - число коллизий / проб
  - загрузка таблицы
  - макс./средняя длина цепочки или кластера
  - количество кластеров
  - худший случай поиска
- **Обучающая панель** справа с описанием выбранного метода.

## Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone <URL_РЕПОЗИТОРИЯ>
cd <папка_проекта>

# 2. Создать виртуальное окружение (рекомендуется)
python -m venv .venv
source .venv/bin/activate        # Linux/macOS
# .venv\Scripts\activate         # Windows

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Запустить приложение
streamlit run app.py
